Homogeneous Flood-MAR dissolved-O2 band diagnostic
==========================================================================================

The plotted dissolved-O2 concentration is:
C_O2_liq = xO2_liq * rhoMolar_liq * 31.998 / 1e6 [g/cm3]

Therefore a visible band can arise from:
  1. xO2_liq itself,
  2. rhoMolar_liq,
  3. or both.

Figure A separates these terms directly.
The white contour is Sgas = 0.01.

Figure B tests whether the concentration band also corresponds to:
  - a true total-O2 inventory maximum,
  - a gas-pressure anomaly,
  - or a phase-presence transition.

Unique phase-presence codes in selected outputs:
  1.0, 3.0

Interpretation guide
--------------------
A. If the band is visible in dissolved O2 AND xO2_liq:
   -> composition / gas-liquid partitioning is involved.

B. If the band is strong in dissolved O2 but weak/absent in xO2_liq,
   while rhoMolar_liq shows the same band:
   -> the feature is mainly generated by liquid molar-density variation.

C. If the band tracks Sgas~0 or a phase-presence boundary:
   -> phase appearance/disappearance is strongly implicated.

D. If total O2 bulk storage does NOT contain the same band:
   -> it is not a true local accumulation of total oxygen inventory.

E. If the band coincides with a strong positive pgas-Patm anomaly:
   -> gas compression may contribute.
   If not, compressed-gas accumulation is not supported.
