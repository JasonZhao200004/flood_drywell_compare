96-240 h:
Water remaining in the 1.22 m diameter drywell is treated as a finite
0-D reservoir.

Reservoir geometry:
radius = 0.61 m

Reservoir update:

Q_well > 0 : porous medium -> reservoir

The reservoir state is updated once after each accepted DuMuX timestep.
